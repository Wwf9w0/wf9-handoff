# Code of Conduct

## Our Commitment

WF9 Handoff aims to maintain a professional, welcoming, and technically constructive open-source community.

We welcome contributors regardless of experience level, background, identity, nationality, language, or location.

## Expected Behavior

Community members are expected to:

- communicate respectfully
- critique ideas and code rather than people
- provide actionable technical feedback
- assume good faith while remaining evidence-driven
- respect project scope and maintainer decisions
- avoid harassment, discrimination, intimidation, and personal attacks
- protect confidential or security-sensitive information

Strong technical disagreement is welcome.

Disrespectful behavior is not.

## Unacceptable Behavior

Examples include:

- harassment or threats
- discriminatory language
- personal insults
- sustained disruption
- publishing private information without permission
- intentionally submitting malicious code
- abusing security reports
- spam or promotional abuse
- sexualized or otherwise inappropriate conduct

## Technical Discussions

Engineering decisions should be evaluated based on:

- correctness
- evidence
- maintainability
- security
- simplicity
- compatibility
- project goals

Avoid turning technical disagreements into personal disputes.

## Enforcement

Maintainers may:

- edit or remove inappropriate content
- close discussions
- reject contributions
- temporarily restrict participation
- permanently ban participants in serious cases

Enforcement should be proportionate and applied consistently.

## Reporting

If you experience or witness unacceptable behavior, contact the project maintainers privately through the contact method published at:

https://wf9labs.com

Reports will be handled as confidentially as reasonably possible.

## Scope

This Code of Conduct applies to official project spaces, including:

- GitHub issues
- pull requests
- discussions
- repository comments
- official community channels
- project-related events or communications

## Attribution

This policy is inspired by common open-source community standards while remaining intentionally concise for WF9 Handoff.
