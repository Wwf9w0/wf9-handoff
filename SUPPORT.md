# Support

WF9 Handoff is an open-source project under active development.

## Where to Ask for Help

Use the following channels depending on your request.

### Bug

Open a GitHub issue using the bug-report template.

Include:

- operating system
- Node.js version
- pnpm version
- Git version
- WF9 Handoff version or commit
- command executed
- expected behavior
- actual behavior
- minimal reproduction if possible

### Feature Request

Use the feature-request template.

The strongest requests explain a real project-continuity failure between coding agents.

### Usage Question

Use GitHub Discussions if enabled.

If Discussions are not enabled, open a focused issue and clearly label it as a question.

### Security Issue

Do not open a public issue.

See [SECURITY.md](SECURITY.md).

## What Support Does Not Include

Maintainers cannot guarantee support for:

- custom forks
- unofficial agent wrappers
- heavily modified local installations
- unsupported Node.js versions
- private third-party tools that cannot be reproduced

## Early Development Notice

WF9 Handoff is currently evolving quickly.

Commands, schemas, adapters, and file formats may change before the first stable release.
